# Política de Privacidad - Platzi Cinema Mode

**Última actualización:** 4 de mayo de 2026

En Platzi Cinema Mode, la privacidad de nuestros usuarios es una prioridad. Esta política detalla cómo se gestionan los datos en nuestra extensión de Chrome.

---

## 1. Recopilación de Información

Platzi Cinema Mode **NO** recopila, almacena ni transmite ningún tipo de información personal, sensible o de identificación del usuario.

- No solicitamos correos electrónicos, nombres o datos de contacto.
- No rastreamos el historial de navegación fuera de las funciones específicas de la extensión en el dominio permitido.

---

## 2. Uso de Datos y Permisos

La extensión funciona exclusivamente en el dominio [platzi.com/cursos/](https://platzi.com/cursos/). Los permisos solicitados se utilizan de la siguiente manera:

- **Lectura y modificación de sitios:** Se utiliza únicamente para inyectar el botón "Modo Cine" y aplicar clases de CSS que modifican la apariencia visual del reproductor de video.
- **Interacción local:** Todas las acciones ocurren localmente en el navegador del usuario.

---

## 3. Almacenamiento de Datos

Esta extensión no utiliza bases de datos externas ni servidores propios. No se guarda información en el almacenamiento persistente del navegador (`chrome.storage`) ni se comparten datos con terceros.

---

## 4. Seguridad

Al no recolectar datos, no existe riesgo de filtración de información personal por parte de esta extensión. El código es una herramienta de mejora de interfaz de usuario (UI) pura.

---

## 5. Cumplimiento de Políticas

Certificamos que el uso de los datos cumple estrictamente con las [Políticas del Programa para Desarrolladores de Chrome Web Store](https://developer.chrome.com/docs/webstore/program-policies/), incluyendo las limitaciones de uso de Google.
